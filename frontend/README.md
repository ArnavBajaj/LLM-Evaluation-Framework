# Frontend

React + TypeScript dashboard for leaderboard analysis, prompt search, model comparison, and failure exploration.

## Planned structure

- src/dashboard: page shells and layouts
- src/charts: reusable chart components
- src/leaderboards: leaderboard views
- src/filters: model, prompt, and run filters
- src/evaluation-runs: run detail pages
- src/prompt-library: prompt browsing and editing
- src/reports: report download and rendering views
